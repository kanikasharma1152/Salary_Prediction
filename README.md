# Salary Prediction Using Data Science

## Overview

This project focuses on analyzing employee salary data and building a machine learning model to predict salaries based on years of experience and other employee-related factors. The project demonstrates the complete data science workflow, including data preprocessing, exploratory data analysis, visualization, model training, and prediction.

## Objectives

* Analyze employee salary data.
* Understand the relationship between experience and salary.
* Perform data cleaning and preprocessing.
* Visualize important patterns in the dataset.
* Build a salary prediction model.
* Generate salary predictions for new employee data.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Scikit-Learn
* Kaggle Notebook

## Dataset Features

The dataset includes information such as:

* Age
* Gender
* Education Level
* Job Title
* Years of Experience
* Salary

## Project Workflow

### 1. Data Collection

The dataset was obtained from Kaggle and loaded into a Kaggle Notebook environment.

### 2. Data Cleaning

* Checked for missing values.
* Handled null values where necessary.
* Verified data types and dataset structure.

### 3. Exploratory Data Analysis (EDA)

* Analyzed salary distributions.
* Examined employee experience levels.
* Explored relationships between different variables.

### 4. Data Visualization

Created visualizations to better understand:

* Salary trends
* Experience vs Salary relationship
* Overall dataset patterns

### 5. Model Building

A machine learning model was trained using employee data to predict salaries based on experience and other relevant features.

### 6. Prediction

The trained model can estimate salaries for new employee records.

## Results

The project successfully demonstrates how data science techniques can be used to analyze employee data and make salary predictions. The results highlight the strong relationship between work experience and salary growth.
